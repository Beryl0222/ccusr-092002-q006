# 重症场外护理证据链 · 照护假核验服务

工会与人力资源部门共建的照护假核验服务。医院或合规见证方依据个案时间线签发**最小化证明**，员工再把证明关联到班次、请假类型与实际照护时段；系统按当期制度拆分核准区间，全程不暴露诊断信息。

`contracts/care_timeline.json` 保存公开的领域样例（住院区间、紧急文书、转院协助等事件），用来约定外部数据的名称与层级；样例不含真实个人资料、业务凭据或生产连接信息。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 个案时间线 | `care_timeline.json` 约定的住院区间、紧急文书、转院协助等事件 |
| 最小化证明 | 只含个案号、照护人、覆盖区间与有效期；HMAC 签名可验真伪，签发端守卫拦截诊断类字段 |
| 请假申请 | 员工把证明关联到照护时段（待命/现场/远程办理）、班次与年假区间 |
| 当期制度 | 版本化的拆分规则，按照护发生日选取，快照钉进每笔核准决定 |
| 核准决定 | 拆分结果：核准区间 + 排除区间（含原因）+ 合计，附最终复核决定 |
| 差额调整 | 医院更正或劳动仲裁只产生新版本与差额，历史记录不改动 |
| 角色视图 | 主管看排班影响、薪酬看已核准区间、争议处理人经授权看证据链 |

## 拆分规则（当期制度）

- **跨午夜待命**：按自然日拆段，分别计入各自日期；
- **远程办理手续**：按制度比例折算工时并按日封顶（v1：50%、每日 4 小时；v2 起 60%、6 小时）；
- **多名亲属轮换**：同一个案同一时段只计一名照护人，按申报先后分配，重叠部分记 `rotation_overlap`；
- **与年假重叠**：重叠部分剔除，记 `annual_leave_overlap`；
- **重复上传**：证明按内容哈希幂等（重复上传返回原证明），申请内/同人重复时段记 `duplicate*`，均不增加假期；
- **覆盖之外**：证明覆盖区间外的时段记 `outside_proof_coverage`。

## 版本与差额

- 医院更正证明 → 证明链产生新版本（旧版本 `superseded`），受影响的已核准申请重算，生成 `hospital_correction` 差额调整；
- 劳动仲裁 → 按裁决恢复被排除的重叠时间（`reinstate_reasons`），生成新版本决定与 `arbitration` 差额调整；
- 差额为零时不产生调整记录；薪资调整（`PAY-*`）挂接差额调整，供审计反向复原。

## HTTP 接口

| 方法与路径 | 说明 |
| --- | --- |
| `GET /health` | 服务身份 |
| `POST /issuers` | 登记签发方（hospital / witness） |
| `POST /proofs` | 签发最小化证明（重复上传幂等） |
| `GET /proofs/:id/verify` | 核验真伪、有效期与版本状态 |
| `POST /proofs/:id/corrections` | 医院更正 → 新版本 + 差额调整 |
| `POST /claims` | 员工申报（关联证明、照护时段、班次、年假） |
| `POST /claims/:id/decisions` | 按当期制度核准 |
| `POST /cases/:id/arbitrations` | 劳动仲裁 → 恢复重叠 + 差额调整 |
| `POST /cases/:id/authorizations` | 授予争议处理人查看授权 |
| `GET /claims/:id/views/supervisor` | 主管视图（仅排班影响） |
| `GET /claims/:id/views/payroll` | 薪酬视图（仅已核准区间与差额） |
| `GET /cases/:id/views/dispute` | 争议视图（需 `x-grantee` 持有效授权） |
| `GET /claims/:id/disclosure-preview?audience=...` | 员工预览将向该角色披露的字段 |
| `POST /payroll-adjustments` | 薪资调整挂接差额 |
| `GET /payroll-adjustments/:id/reconstruction` | 复原：所用制度、凭证状态、排除的重叠时间、最终复核决定 |

## 运行

```bash
npm run check   # 基础检查
npm test        # 全部测试
npm start       # 启动服务（默认 8000 端口，--port 可改）
```

## 模块结构

```
src/
  service.js          HTTP 路由与服务入口
  lib/
    canonical.js      规范化序列化、SHA-256、HMAC 签名
    intervals.js      半开区间代数（交/并/差/跨午夜拆段/时区格式化）
    policy.js         当期制度登记与版本选择
    proofs.js         证明签发、核验、去重、版本更正
    splitting.js      拆分引擎（轮换/跨午夜/远程折算/年假剔除/去重）
    ledger.js         申请、核准决定、更正、仲裁、差额与薪资挂接
    views.js          主管/薪酬/争议三种角色视图与授权
    disclosure.js     员工披露预览（与视图同源）
    audit.js          从薪资调整复原制度、凭证、排除与复核决定
    store.js          只增不删的内存台账
```

## 隐私与审计保证

- 证明与所有视图均不含诊断、病历等医疗细节（签发端强制拦截）；
- 每个角色只看到其职责所需的最小字段，员工可事先预览披露内容；
- 所有记录只增不删，任何一笔薪资调整都能复原出当时的制度版本、凭证状态、被排除的重叠时间和最终复核决定。
